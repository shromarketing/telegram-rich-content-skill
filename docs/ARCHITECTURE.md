# Architecture

The repository combines an agent skill with deterministic local tools. The agent handles
editorial judgment; scripts handle repeatable acquisition, validation, diagnostics, and
explicitly approved delivery.

```text
source
  -> source/transcript
  -> evidence map
  -> content brief + approved voice profile
  -> plain fallback + Rich HTML
  -> strict local validation + approximate preview
  -> private Telegram test
  -> separate production approval
```

The material package generated by `scripts/init_material.py` is the handoff boundary.
It keeps claims traceable and lets a human review the exact source, post variants, media,
and validation status without reconstructing an agent conversation.

## Trust boundaries

- Source extraction may use public web or local files; rights and access remain the
  user's responsibility.
- Voice profiles and unpublished materials stay project-local unless the user chooses
  otherwise.
- Transcription runs locally. A one-time model download may contact the model host.
- Validation and preview are offline.
- Telegram is contacted only by a diagnostics command with `--telegram` or a publisher
  with `--send` and exact target confirmation.
- Telegram clients are the final rendering authority.
