# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] - 2026-08-27

### Added

- source-to-post workflow for ideas, audio, articles, documents, and video;
- Codex and Claude Code skill packaging;
- local `faster-whisper` transcription with TXT, Markdown, SRT, VTT, JSON,
  word timestamps, semantic blocks, checkpoints, and resume;
- optional Apple Silicon `mlx-whisper` backend;
- YouTube thumbnail, caption, metadata, and audio acquisition through `yt-dlp`;
- strict Bot API 10.3 Rich HTML validator and approximate offline preview;
- dry-run-first Rich Message, plain post, and album publishers;
- installation doctor, selective bootstrap, material-package generator, and
  explainable tone-of-voice guardrails;
- bilingual documentation, synthetic showcase, security model, and CI matrix.
